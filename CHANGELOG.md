# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Production environment configuration for Render deployment with Neon PostgreSQL.
- CORS configuration updated to support production frontend domain via `FRONTEND_URL` environment variable.
- Database configuration updated to read from `DATABASE_URL` environment variable for production.
- SSL configuration enabled in production with proper handling for reverse proxies.
- Docker entrypoint script updated to automatically run database migrations (`db:prepare`) and seeds (`db:seed`) on server startup.

## [0.1.0] - 2026-10-14

### Added

- Configured RSpec as testing framework (`rspec-rails`).
- Configured bind mount volume mapping in `compose.yaml` for live host/container syncing.
- Initial Rails API application bootstrap (Ruby 3.4.10, Rails 8.1.3).
- Docker-first environment configuration with `Dockerfile.dev` and `compose.yaml` (PostgreSQL 17.10).
- Project documentation setup (`AGENTS.md` and ADR `0001-docker-first-development.md`).
- Added development helper scripts (`bin/dev` and `bin/run`).
- Documentation: ADR `0002-development-bind-mount-and-helper-scripts.md`.
- API versioning architecture established under `Api::V1` namespace.
- Configured CORS middleware (`rack-cors`) to allow cross-origin requests for local frontend development (`http://localhost:5173`).
- Configured Devise and `devise-jwt` for user authentication.
- Added custom `RegistrationsController` and `SessionsController` under `/api/v1`.
- Updated database schema annotations on models using `annotate`.

### Removed

- Removed default `test/` directory generated by Rails (Minitest).
